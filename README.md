# 🧮 Simple Calculator

A clean and responsive web-based calculator built using HTML, CSS, and JavaScript. The application allows users to perform basic arithmetic operations through an interactive and user-friendly interface.

## 🌐 Live Demo

🔗 https://simple-calculator-eight-ruby.vercel.app/

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🧹 Clear calculator input
* 🔢 Decimal number calculations
* 📱 Responsive design
* ⚡ Fast and interactive user experience

## 🛠️ Technologies Used

* **HTML** – Structure of the application
* **CSS** – Styling and responsive design
* **JavaScript** – Calculator functionality and logic
* **Vercel** – Deployment and hosting

simple-calculator/

## ▶️ How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/Ayesha-svc/simple-calculator.git
```

### 2. Navigate to the project folder

```bash
cd simple-calculator
```

### 3. Open the application

Open `index.html` in your preferred web browser.
